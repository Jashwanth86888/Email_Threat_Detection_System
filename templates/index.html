🌐 Computer Networks & Machine Learning Concepts Implemented:

  • SMTP Architecture (RFC 5321 vs RFC 5322): Demonstrates how the envelope sender (Return-Path) diverges from the displayed From: header.
  • DNS Resolution & MX Records: Verifies domain existence (A/AAAA records) and Mail Exchange (MX) server records using DNS protocols.
  • Email Authentication Protocols: Inspects SPF (IP authorization via DNS TXT), DKIM (cryptographic signatures), and DMARC alignment.
  • Transport & Application Layer Analysis: Evaluates HTTP (cleartext, port 80) vs HTTPS (TLS/SSL, port 443) and identifies direct IPv4 usage in hyperlinks.
  • Multi-Hop SMTP Routing: Parses chained Received: headers to trace message traversal through intermediate Mail Transfer Agents (MTAs).
  • AI / ML Ensemble Learning: Combines deterministic rule-based protocol heuristics with a TF-IDF & Logistic Regression classifier, computing an ensemble average score to minimize false positives and negatives.
